# Slip

Mac-to-Mac clipboard, files and keyboard/mouse over the LAN. Menu bar, no account, no cloud.

## Rules

- Scoped and terse. One feature solid before the next. No bloat.
- Validate often: `swift build` + `swift run slip --selftest`.
- Native only. No Electron/Tauri/daemon/deps.
- Secure by default: encrypted + authenticated, no plaintext fallback.
- No perf leaks: poll only while connected, stream framed, mmap files, one connection, cap payloads.
- KVM opt-in and gated. Input swallowed only while cursor is remote, local always passes through. Disconnect/crash/permission-loss restore local input.
- UI: system font, small, tone hierarchy, no accent color, no chrome.

## Does

| Item | Behavior |
|---|---|
| Text / images | copy, paste both ways. Images as PNG. |
| Files | copy them, land in `~/Downloads/Slip` + on clipboard |
| Roles | Host or Join, persisted. Host shows a code, Join enters it. |
| Discovery | Bonjour, host by name |
| Liveness | ping 4s, silent drop detected in 12s, Join auto-reconnects |
| Keyboard & mouse | opt-in KVM, Host controls, cursor crosses the edge, keyboard follows, failsafe Ctrl-Opt-Cmd-Esc |

Poll 0.4s, only while connected. Payload cap 64 MB.

## Security

- Trust: both Macs same owner. That premise lets clipboard sync exist.
- Link: TLS 1.2 ECDHE-PSK (forward secrecy) from the code. PBKDF2-HMAC-SHA256, 200k.
- Code: 10 Crockford-base32 chars (~50 bits), shown on Host, typed on Join.
- New conn adopted only after it authenticates, so an unauth connector can't drop the live link.
- Leak guard: skip `ConcealedType` / `TransientType` / `AutoGeneratedType`.
- LAN only, one paired connection.
- Caveat: ECDHE-PSK gives forward secrecy, so a captured handshake can't be decrypted even if the code is later cracked. A live MITM who guesses the ~50-bit code (slowed by PBKDF2) could still impersonate a peer. Fine for same-owner LAN, not hostile networks.

## Architecture

```
NSPasteboard <-> Clipboard <-> Core <-> Link <-> TLS-PSK / Bonjour <-> other Mac
CGEventTap   <-> KVM(Controller/Receiver) <-> Core
                 Panel (SwiftUI in a borderless window)
```

Sources grouped by concern under `Sources/slip/`:

| Folder / file | Role |
|---|---|
| `App/main`, `App/AppDelegate` | entry (or `--selftest`), status item + panel window + icon |
| `Core/Core` | state, wires Share + Link + KVM |
| `Core/Settings` | prefs + config file |
| `Core/Log` | diagnostic log, config-gated, self-trimming |
| `Link/Link` | Network.framework: Bonjour, TLS-PSK, framing, heartbeat, reconnect |
| `Link/Wire` | frame format + PBKDF2 |
| `Link/SelfTest` | loopback TLS-PSK + framing |
| `Share/Clipboard` | poll, read, apply, echo suppression |
| `Share/Files` | file -> frame, save without overwrite |
| `KVM/KVM` | ties capture/inject to the link by role, watchdog |
| `KVM/KVMController` | Host capture, edge crossing, swallow, stream |
| `KVM/KVMReceiver` | Join inject, hand back |
| `KVM/CursorHide` | private CGS, hide cursor from an accessory app |
| `KVM/Input` | KVM events, binary codec |
| `KVM/Layout` | monitor side + CG geometry |
| `KVM/Permissions` | Accessibility + Input Monitoring |
| `UI/Panel` | UI |
| `UI/Tokens` | layout + type tokens |

Frame: `[4B hdrLen][hdr JSON][8B payloadLen][payload]`, big-endian. Kinds: `hello ping text image file input`. `input` payload is binary (not JSON).

`Link` is a state machine on one serial queue: `epoch` invalidates stale callbacks on teardown, a new conn is promoted only on `.ready`.

## Build

```
./build.sh                    # release, assemble + sign Slip.app
open Slip.app
swift run slip --selftest
```

- First run prompts Local Network (Bonjour). Allow on both.
- Apple Silicon only (build compiles for the host arch).
- Signing: a stable self-signed identity keeps TCC grants across rebuilds. Ad-hoc fallback (no identity set) re-keys each rebuild, so grants and the Local Network prompt reset.
- Copying to the other Mac sets quarantine: `xattr -dr com.apple.quarantine Slip.app` or right-click > Open.

## Keyboard and mouse (built)

- Host active session CGEventTap. On crossing: detach cursor (`CGAssociateMouseAndMouseCursorPosition(0)`), hide, stream deltas + keys + scroll as `input`. Join injects via `CGEventPost`, hands back on exit edge. Same approach Deskflow converged to (detach + deltas), lan-mouse uses it.
- Safety: swallow only while remote; failsafe Ctrl-Opt-Cmd-Esc; 0.5s watchdog tears the tap down if Accessibility/Input Monitoring is revoked or re-enables a silently-disabled tap; disconnect restores local. Real AppKit app so detach + watchdog tick (the deskflow lockout was a missing Cocoa run loop).
- Needs Accessibility + Input Monitoring on the controller.
- Limits: single display per Mac, same keyboard layout, injected clicks may not focus a background window, no trackpad gestures.

## Known limitations

- No feedback yet on Local Network denied.
- Two Macs with the same name can't pair (joiner filters its own name).
- No in-app auto-start (add via Login Items).
- RTF-only clipboard not sent.
- Sleep/wake reconnect works in design, verify on hardware (esp. host sleeping).

## Research

- Deskflow: server/client TCP, clipboard CCLP/DCLP, chunked files, no discovery, TLS pinned. macOS input via CGEventTap/Post, needs Accessibility + Input Monitoring. Lockout trap: revoking Accessibility with a live tap, no Cocoa run loop. We avoid the data-path tap entirely for clipboard; KVM only swallows while remote + watchdog.
- DeskHop: hardware KVM, same-height edge crossing, both ends live, switch = routing flag. No clipboard (trust boundary). Named the slide metaphor.
- Perpetua: Python + Rust/Tauri KVM. Borrowed: Bonjour + OTP pairing, clipboard-only mode. Avoided: multi-runtime bloat, IP-only auth, unfiltered clipboard broadcast.
- lan-mouse / MacKVM: detach + raw deltas, scroll-inversion normalization, cross-layout remap, per-key repeat, failsafe hotkey.
